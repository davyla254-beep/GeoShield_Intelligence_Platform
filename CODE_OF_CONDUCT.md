# GeoShield Intelligence Platform Code of Conduct

## Our Commitment

GeoShield Intelligence Platform is committed to fostering a professional, inclusive, respectful, and collaborative environment for all contributors.

Every participant is expected to contribute in a manner that promotes constructive collaboration, technical excellence, and ethical responsibility.

---

# Professional Standards

All contributors are expected to:

* Treat everyone with respect and professionalism.
* Communicate constructively and courteously.
* Accept technical feedback professionally.
* Encourage knowledge sharing and mentorship.
* Maintain high standards of engineering practice.
* Support an environment free from discrimination and harassment.

---

# Expected Behaviour

Examples of positive behaviour include:

* Using respectful language.
* Providing constructive code reviews.
* Reporting bugs responsibly.
* Following project documentation.
* Writing maintainable and well-documented code.
* Respecting differing technical opinions.

---

# Unacceptable Behaviour

The following behaviours are not permitted:

* Harassment or intimidation.
* Personal attacks or insults.
* Discriminatory language or behaviour.
* Sharing confidential information without authorization.
* Deliberately introducing malicious code.
* Misrepresenting work or claiming another person's contributions as your own.
* Any activity intended to disrupt project development.

---

# Artificial Intelligence Ethics

GeoShield develops Artificial Intelligence systems intended to support disaster intelligence and geospatial decision-making.

Contributors must ensure that AI components:

* Prioritize human safety.
* Produce transparent and explainable outputs.
* Avoid intentional bias.
* Respect privacy and applicable data protection requirements.
* Are used for lawful and ethical purposes.

---

# Security Responsibility

All contributors share responsibility for protecting the platform.

Do not:

* Expose credentials.
* Commit API keys.
* Share authentication tokens.
* Upload sensitive datasets without authorization.

Security vulnerabilities should be reported privately to the project maintainer.

---

# Enforcement

Project maintainers reserve the right to remove, edit, or reject contributions that violate this Code of Conduct.

Repeated or severe violations may result in temporary or permanent removal from the project.

---

# Scope

This Code of Conduct applies to:

* GitHub Issues
* Pull Requests
* Discussions
* Documentation
* Project communications
* Community interactions related to GeoShield

---

# Reporting Violations

If you observe behaviour that violates this Code of Conduct, report it directly to the project maintainer.

Reports will be handled confidentially and reviewed promptly.
